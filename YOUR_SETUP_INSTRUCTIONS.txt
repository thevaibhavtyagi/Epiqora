YOUR 3-STEP SETUP
═══════════════════════════════════════════════════════════════════════════════

STEP 1: CREATE .env FILE (2 minutes)
────────────────────────────────────────────────────────────────────────────

In VS Code:
1. Look at the left sidebar, find "backend" folder
2. Right-click "backend" → "New File"
3. Name the file: .env
4. Copy this into the file:

    PORT=5000
    NODE_ENV=development
    GEMINI_API_KEY=YOUR_ACTUAL_API_KEY_HERE

5. Replace YOUR_ACTUAL_API_KEY_HERE with your real Gemini API key
6. Save (Ctrl+S)

That's it! One file. Contains your API key. CRITICAL.


STEP 2: START BACKEND (3 minutes)
────────────────────────────────────────────────────────────────────────────

In VS Code:
1. Open Terminal: Click at bottom of screen or press Ctrl + `
2. You should see command prompt/terminal
3. Type these commands:

    cd backend
    npm install
    npm start

4. WAIT for npm install (takes 1-2 minutes)
5. You should see:

    ✓ added X packages
    [Server] Listening on port 5000
    [Server] Environment: development

6. DO NOT CLOSE THIS TERMINAL. Leave it running.

✓ Backend is now running!


STEP 3: START FRONTEND (2 minutes)
────────────────────────────────────────────────────────────────────────────

In VS Code:
1. Open a SECOND terminal: Click + icon at top of terminal or Ctrl+Shift+`
2. You now have TWO terminals (both visible at bottom)
3. In the new terminal, type:

    cd frontend
    python -m http.server 3000

4. You should see:

    Serving HTTP on 0.0.0.0 port 3000

5. DO NOT CLOSE THIS TERMINAL EITHER. Leave it running.

✓ Frontend is now running!


STEP 4: OPEN IN BROWSER (1 minute)
────────────────────────────────────────────────────────────────────────────

1. Open Chrome, Firefox, Safari, or Edge
2. Type in address bar: http://localhost:3000
3. Press Enter
4. Beautiful landing page loads!
5. Press F12 to see console - you should see NO red errors

✓ Everything is working!

IF SOMETHING BREAKS
═══════════════════════════════════════════════════════════════════════════════

CHECK 1: Look at Terminal 1 (Backend)
  → Any error messages?
  → Red text?
  → Restart: Ctrl+C, then npm start

CHECK 2: Look at Browser Console (F12)
  → Any red error messages?
  → Blue "i" info messages?
  → Network tab shows failed requests?

CHECK 3: Check .env File
  → Does it exist in backend folder?
  → Does it have PORT=5000?
  → Does it have GEMINI_API_KEY=something?
  → If not, create it again.

CHECK 4: Verify Both Terminals Running
  → Terminal 1: npm start running?
  → Terminal 2: python server running?
  → If not, start them.

CHECK 5: Clear Browser Cache
  → Press Ctrl+Shift+Delete (Windows)
  → Or Cmd+Shift+Delete (Mac)
  → Clear all history
  → Reload page (F5)

Most problems are:
  ① Missing .env file
  ② Missing API key
  ③ Backend not running
  ④ Browser cache issues
  ⑤ Wrong port numbers


COMMON ISSUES
═══════════════════════════════════════════════════════════════════════════════

Issue: "Port 5000 already in use"
Fix:   Change PORT in .env to 5001 (or another number)

Issue: "Cannot find module"
Fix:   Run: cd backend && npm install

Issue: "GEMINI_API_KEY not found"
Fix:   Check .env file in backend folder, add API key

Issue: App loads but chat doesn't work
Fix:   Check backend terminal for errors, check F12 console

Issue: "No face detected" when uploading photo
Fix:   Try a different, clearer photo with good lighting

Issue: Browser shows connection refused
Fix:   Check both terminals are running, check ports are correct
