## 🚀 Quick 1-2-3 Setup

If you want to just do it NOW:

```bash
# Step 1: Create .env file in backend folder
# Content:
PORT=5000
NODE_ENV=development
GEMINI_API_KEY=your_api_key_here

# Step 2: Terminal 1
cd backend
npm install
npm start

# Step 3: Terminal 2
cd frontend
python -m http.server 3000

# Browser
http://localhost:3000
```

Done! ✅
